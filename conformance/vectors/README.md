`SHA256SUMS` holds the SHA-256 of every file in `core/`, `qa-assets/` and `bip340/`, as found at the pinned commit. The runner's tests fail when a file differs from its recorded hash or a file is not listed; `shasum -a 256 -c SHA256SUMS` in this directory checks the same by hand. The `core` workflow also compares the files in `core/` with `src/test/data/` of its Bitcoin Core v32.1 checkout.
